TidyDesktop {VERSION}
====================
만든 곳: 404아키텍트  ·  https://www.404architect.com
(English: README.en.txt)

바탕화면 아이콘을 "상자"로 묶어 정리해 주는 프로그램입니다.
진짜 바탕화면 아이콘을 그대로 쓰기 때문에, 아이콘을 더블클릭해서 여는 것,
우클릭 메뉴, 끌어서 놓기는 평소와 똑같이 됩니다.


1. 실행하기
-----------
TidyDesktop.exe를 원하는 폴더(예: 문서 폴더)에 두고 실행하세요. 설치는 필요 없습니다.

※ "Windows의 PC 보호" 창이 뜨면 "추가 정보"를 누른 뒤 "실행"을 누르세요.
   Microsoft 인증 서명이 없는 프로그램이라 나오는 경고입니다.
   백신 프로그램이 확인을 요청할 수도 있습니다.

※ 실행하면 작업 표시줄 오른쪽 아래(시계 옆)에 아이콘이 생깁니다.
   모든 메뉴는 이 아이콘을 우클릭하면 나옵니다.
   보이지 않으면 시계 옆의 ^ 버튼을 눌러 보세요.


2. 처음 실행하면 바뀌는 것
--------------------------
- 바탕화면의 "아이콘 자동 정렬"과 "아이콘을 격자에 맞춤"이 꺼집니다.
  (상자 안에 아이콘을 자유롭게 놓기 위해서입니다)
- "정리함" 상자가 하나 생깁니다.
- 처음 실행할 때의 아이콘 위치를 따로 저장해 둡니다. 언제든 되돌릴 수 있습니다.


3. 기본 사용법
--------------
- 트레이 메뉴 > "용도별 자동 정리": 아이콘을 인터넷, 오피스, 게임, 사진, 문서 … 상자로 나눠 담습니다.
- 아이콘을 상자 안으로 끌어 놓으면 그 상자에 들어가고, 밖으로 끌어내면 빠집니다.
- 상자 제목을 끌면 상자가 옮겨집니다. 테두리(왼쪽, 오른쪽, 아래)를 끌면 크기가 바뀝니다.
  Shift를 누른 채 끌면 줄이 딱딱 맞습니다.
- 상자 제목을 더블클릭하면 접히고 펼쳐집니다.
- 상자 제목을 우클릭하면: 꾸미기(이름, 색, 투명도), 이름 바꾸기, 정렬, 위치 잠금, 삭제 등이 있습니다.
- 최근 기록 상자: 바탕화면에 생기고, 지워지고, 이름이 바뀐 파일이 표시됩니다.
  다른 폴더로 옮겨진 파일은 어디로 갔는지, 휴지통으로 갔는지도 알려 줍니다.
  항목을 누르면 바탕화면에 있는 파일은 열리고, 다른 곳으로 간 파일은 그 폴더가 열립니다.
- 트레이 메뉴 > "파일 규칙…": 예를 들어 "mp4 파일은 동영상 폴더로 옮기기" 같은 규칙을 만들 수 있습니다.
  규칙으로 옮겨진 파일은 최근 기록 상자의 "되돌리기"로 원래 자리에 돌려놓을 수 있습니다.
  ※ 규칙은 실제 파일을 옮기므로, 조건을 정확히 정해 주세요.
- 트레이 메뉴 > "Windows 시작 시 자동 실행": 컴퓨터를 켤 때마다 자동으로 실행됩니다.
- 트레이 메뉴 > "Language / 언어": 한국어, 영어, 일본어, 중국어, 스페인어, 독일어, 프랑스어, 포르투갈어, 러시아어 중 선택할 수 있습니다. (기본값: Windows 언어 설정)

4. 되돌리기
-----------
- 배치를 잘못 바꿨을 때: 트레이 메뉴 > "저장된 배치로 되돌리기"에서 시간을 고르세요.
  (자동으로 30분마다, 그리고 크게 바꾸기 직전마다 저장됩니다)
- 처음 상태로 완전히 되돌릴 때: 트레이 메뉴 > "상자 모두 지우고 아이콘 원래 위치로 복원"


5. 지우기 (제거)
----------------
1) 트레이 메뉴 > "상자 모두 지우고 아이콘 원래 위치로 복원"
2) 트레이 메뉴 > "Windows 시작 시 자동 실행"이 켜져 있으면 끄기
3) 트레이 메뉴 > "종료"
4) TidyDesktop.exe 삭제
5) 설정까지 지우려면: 윈도우 키 + R > %APPDATA%\TidyDesktop 입력 > 열린 폴더 삭제


6. 알아 두실 점
---------------
- 설정과 기록은 %APPDATA%\TidyDesktop 폴더에만 저장되고, 인터넷으로 보내지 않습니다.
- 바탕화면에서 사라진 파일이 어디로 갔는지 알려 주기 위해, 이 컴퓨터의 드라이브에서
  파일 이름이 바뀌거나 새로 생기는 것을 잠깐씩 확인합니다. 파일 내용은 읽지 않고,
  바탕화면에서 사라진 파일과 이름이 같은 경우만 기록에 남깁니다.
- 새 언어를 추가하려면 소스코드의 Languages/en.json을 번역하여 TidyDesktop.exe 옆의
  "Languages" 폴더에 넣으면 프로그램이 자동으로 인식합니다.
- 문제가 생겨 log.txt를 다른 사람에게 보낼 때는, 바탕화면 파일 이름이 들어 있다는 점을 알아 두세요.
- Windows 10 / 11 용입니다.
